Address business, technical, visual, accessibility, usability and operational criteria for software increments. Mark a dimension not applicable only with a reason. Criteria and reference counts are sizing guidance, not imposed execution limits.

## Exit and return

Run producer checks; publish the candidate promptly; verify remote retrieval. Preserve private evidence separately. Add real R/V blockers while remaining in the producer phase. After both examinations complete, submit the same frozen candidate into native review. Never silently correct a failed candidate before the native return. On changes requested, correct as the original producer, publish a new SHA, obtain fresh affected evidence and resubmit. No self-acceptance or implied merge/deploy.
