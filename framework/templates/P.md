## Exit and return

Stage in backlog under the intended producer. Before release, fill scope, criteria and reachable immutable inputs. Verify the resolved agent repository/branch under the deliberate project `adapter_default` configuration, or the explicitly configured alternative.

Run producer checks; publish the candidate promptly; verify remote retrieval. Save/read back the candidate manifest and private evidence before releasing separate R/V with full SHA, paths and document revisions. Add real R/V blockers while remaining in the producer phase; they never depend on source completion. Keep unresolved source acceptance edges when an authorized separate production assignment is needed. A completed FAIL report is evidence, not acceptance.

After both examinations complete, save/read back exact candidate, report revisions, findings, limitations and [continuation](../continuation.md), then submit the same frozen candidate into configured native review as the final required action of the run. The incoming participant verifies native stage/currentParticipant, original returnAssignee and candidate in its own context. Never require an outgoing post-transition receipt or silently correct a failed candidate before the native return. On changes requested, verify the native return as original producer, publish a new SHA, obtain fresh affected evidence and resubmit. Reconcile interrupted operations before retry; UNKNOWN is not retry authority. No self-acceptance or implied merge/deploy.
